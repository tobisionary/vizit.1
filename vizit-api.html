Building with the Vizit API.

+What can I do with the Vizit API?
Submit any image or PDP and Vizit's agents score, diagnose, recommend, and optimize it. Every response uses the same Content Conversion Standard that powers the Vizit platform — so a score returned by the API is the same score returned in the Vizit platform.
+How is the Vizit API different from a generic image API?
A generic image API tells you what's in an image. The Vizit API tells you whether an image will convert — for a specific audience, in a specific category, in a specific country, against the Content Conversion Standard. It's trained on Vizit's proprietary Visual Conversion Graph.
+Does the API support catalog-scale volume?
Yes. Image scoring is asynchronous — submit, then poll for results. PDP submissions are designed for continuous ingestion across millions of SKUs.
+Can I optimize images through the API, not just score them?
Yes. Submit any asset and receive a higher-scoring optimized variant — generated on-brand and scored against the Content Conversion Standard before it's returned. The same Generative AI optimization that powers Vizit Spark, exposed as an API call.
